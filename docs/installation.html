Installation

Attach a NUKRAX Expert Advisor to MetaTrader 5, step by step.

Requirements

  • A MetaTrader 5 terminal (desktop) with algo trading permitted.
  • A broker account — demo or live — connected in that terminal.
  • The .ex5 file for your chosen EA, available from your account after purchase.

1. Download the EA file

From your Account dashboard, open the EA you've purchased and download its .ex5 file. This is the compiled, ready-to-run Expert Advisor — no compilation step needed on your end.

2. Copy it into MetaTrader 5

In MetaTrader 5: File → Open Data Folder, then place the file in MQL5/Experts/. Restart the terminal, or right-click Expert Advisors in the Navigator panel and choose Refresh.

File location 
MQL5/
  Experts/
    NUKRAX_APEX_HFT.ex5

3. Attach it to a chart

  1. 01Open the chart for the instrument the EA is designed for (check the product page for the recommended symbol and timeframe).
  2. 02Drag the EA from the Navigator panel onto the chart.
  3. 03In the settings dialog, enable Allow Algo Trading on the Common tab.
  4. 04Review the Inputs tab — see Configuration for what each setting controls.
  5. 05Click OK. A smiley-face icon in the chart's top-right corner means the EA is running.

4. Verify it's running

Tip
Check the terminal's Experts tab (bottom panel) for a startup log line from the EA. If algo trading is disabled globally, MetaTrader shows a red icon instead of a smile — toggle the main Algo Trading button in the toolbar.

Common installation issues

SymptomLikely cause
EA doesn't appear in NavigatorFile wasn't placed in the right Experts folder, or the terminal wasn't restarted.
Red (not green) smiley iconAlgo trading is disabled — check both the chart's EA settings and the toolbar toggle.
No trades placed on demoMarket may be closed, or symbol/timeframe doesn't match the EA's requirements — check the product page.

For anything not covered here, see Troubleshooting.
