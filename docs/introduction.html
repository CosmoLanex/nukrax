Introduction

Everything about the NUKRAX platform — the Expert Advisors, the website, and how it all fits together — in one place.

What NUKRAX is

NUKRAX is a trading technology brand built around three MetaTrader 5 Expert Advisors — APEX HFT, AURUM HFT, and SMC ICT — plus the website, account system, and community that support them. This section of the site documents the platform itself: how its pages fit together, how it's built, and how to get the most out of it.

If you're looking for help using your account, choosing an EA, or navigating the community, start with Getting Started. If you're interested in how the site itself is built — its responsive system, performance work, and architecture — jump to Project Structure.

How to read these docs

Every page in this section follows the same layout: a sidebar on the left for navigating between pages, this content in the middle, and a table of contents on the right for the current page. On mobile, the sidebar becomes a slide-out menu — use the menu button in the top bar to open it.

Throughout the docs you'll see a few recurring boxes:

Note
General context or a detail worth knowing.
Tip
A suggestion that can save you time or improve your setup.
Warning
Something that can cause a problem if missed.
Planned
A feature that doesn't exist yet — included so the docs are ready when it ships.
