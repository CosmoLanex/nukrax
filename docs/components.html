Components

The Expert Advisor product lineup, and the shared UI pieces reused across pages.

Two kinds of “components”

On NUKRAX, "components" means two related things: the Expert Advisor product lineup (the tradable systems themselves), and the shared UI components reused across pages (the auth widget, the AI assistant, the community composer). Both are documented here.

Expert Advisor lineup

APEX HFT
High-frequency execution across multiple timeframes.
AURUM HFT
Structured trade flow with layered risk controls.
SMC ICT
Pure Smart Money Concepts and ICT entry logic.

Compare all three side by side on Execution Systems.

Shared UI components

ComponentWhere it livesPurpose

Design-system components

Reusable visual components — cards, callouts, code blocks, buttons — are documented in CSS & Design System. Layout primitives (container, gutter, grid) are covered in Layout System.
