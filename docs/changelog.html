Recent platform updates

A running log of notable changes to the platform and its documentation. Dated by rough recency rather than exact timestamps.

Documentation system

New A complete documentation section was added under docs/ — sidebar navigation with mobile drawer support, search filtering, copy-to-clipboard code blocks, breadcrumbs, and previous/next navigation, all sharing one consistent template and design system across every page.

Scroll performance pass

Every scroll-linked handler across the site was audited. Fixed: unbatched scroll listeners on the homepage and feedback page (progress bar, nav highlight), layout-thrashing nav highlighters on the EA product pages and this documentation section, a permanent will-change on heading-reveal word-spans, and per-frame layout reads inside the auto-scrolling testimonial/timeline tracks. See Performance for details.

“Get Started” button refinement

The border radius on every "Get Started" button was reduced on desktop screens only, for a slightly less rounded, more premium look — mobile was left untouched.

Centralized responsive architecture

Introduced assets/data/ (shared breakpoints, device detection, responsive math, layout constants, and utilities) and assets/css/tokens.css (shared design tokens, base reset, and @font-face), deduplicated from near-identical copies previously repeated across every page. See Responsive Design and CSS & Design System.

Earlier

  • Full Supabase authentication system: email/password, GitHub OAuth, and magic links.
  • Community platform with real-time feeds, direct messages, likes, follows, and notifications.
  • Three.js 3×3×3 Rubik's-cube hero animation.
  • AI chat widget and full-page assistant ("Lanux"), proxied through a Cloudflare Worker with a local offline fallback responder.
