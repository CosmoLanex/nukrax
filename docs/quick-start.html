Quick Start

The fastest path from a new account to a running Expert Advisor — five steps, no detours.

The five-minute version

  1. 01Create an account and confirm your email.
  2. 02Open Execution Systems and compare APEX HFT, AURUM HFT, and SMC ICT.
  3. 03Follow Installation to attach your chosen EA to MetaTrader 5.
  4. 04Run it on a demo account first — see Configuration for recommended starting inputs.
  5. 05Join the Community to compare notes with other traders running the same system.

Choosing an EA quickly

If you want…Consider
High-frequency execution across multiple timeframesAPEX HFT
Structured trade flow with layered risk controlsAURUM HFT
Pure Smart Money Concepts / ICT entry logicSMC ICT

Each EA's own page has a full breakdown of entry models, exit logic, and risk handling — see Components for a platform-level comparison.

Always demo first

Warning
Run any Expert Advisor on a demo account before committing real capital. Market conditions, broker execution, and your own risk settings all affect live results — a demo run is the only way to confirm a system behaves the way you expect on your own broker feed.

After it's running

Once an EA is live on a chart, you can monitor it from the platform's terminal dashboard — live equity, session stats, and trade history in one view. If anything looks off, Troubleshooting covers the most common setup issues.
