Configuration

Configuration

Expert Advisor inputs and account settings — what's configurable, and where.

Two layers of configuration

"Configuration" on NUKRAX covers two things: the inputs on each Expert Advisor (risk, timing, symbol-specific behavior), and your account settings on the website itself (notifications, security, display preferences). This page covers both.

Expert Advisor inputs

Every EA exposes its tunable inputs on the MetaTrader 5 Inputs tab when you attach it to a chart. Exact parameters differ per system — check the individual product page for the full list — but most NUKRAX EAs share a few common categories:

CategoryTypical inputs
RiskLot sizing method, max risk per trade, daily loss limit.
TimingSession windows, news-event filters, broker GMT offset.
ExecutionEntry model toggles, order type (market vs. laddered stop orders).
Warning
Always confirm your broker's GMT offset before going live — session-based logic depends on it, and a mismatched offset can shift trades outside the intended window.

Account settings

From Settings you can manage security (password, connected GitHub account), notification preferences, and basic display options. Changes save immediately — there's no separate "save" step for most toggles.

Recommended starting point

Tip
Start with default inputs on a demo account before adjusting anything. It's much easier to judge whether a change actually helped once you've seen the default behavior first.

Planned: config profiles

Planned
Saved configuration profiles (so you can switch between a conservative and aggressive input set without re-entering values) are on the roadmap — not available today.
