Feature highlights

A tour of what's available across the platform today.

Three Expert Advisors
APEX HFT, AURUM HFT, and SMC ICT — each with its own execution style. See Components.
Live trading terminal
A real-time dashboard for monitoring equity, sessions, and trade history.
Community feed
Posts, likes, follows, DMs, and notifications, built on Supabase Realtime.
AI assistant ("Lanux")
A chat widget and full-page assistant, proxied through a Cloudflare Worker.
Full account system
Email/password and GitHub OAuth, magic links, profile setup, and public profile pages.
Market Map
A live view surfaced from the main navigation for at-a-glance market context.

Account & authentication

Sign up with email/password, GitHub OAuth, or a magic link. New accounts go through email confirmation and a short profile setup (username availability is checked live) before landing on the dashboard. See Log In and Sign Up.

Community

A private, real-time feed for signed-in traders — posts, likes, follows, direct messages, and notifications. Two reserved handles, @CosmoLanex and @nukrax, are kept for official accounts. See Community.

Trading terminal

The terminal dashboard gives a live view of account performance — equity curve, session breakdowns, and trade history — once an EA is running.

AI assistant (Lanux)

A floating chat widget available site-wide, plus a full-page interface at chat.html. Requests are proxied through a Cloudflare Worker to keep the underlying API key server-side, with a local, offline knowledge-base responder as a fallback when the network call isn't available.

Planned features

Planned
A public API for programmatic account/trade data access is on the roadmap — see API & Integrations for what's confirmed vs. speculative.
