Troubleshooting

Fixes for the most common setup and account issues.

EA attached but not trading

  1. 01Check the chart's top-right corner for a smiley-face icon — a frown means the EA hit an error on init.
  2. 02Confirm Algo Trading is enabled both in the EA's own settings and the main toolbar toggle.
  3. 03Check the terminal's Experts tab for a startup error log.
  4. 04Confirm the symbol and timeframe match what the product page recommends.

See Installation for the full setup walkthrough.

Can't sign in

  • Check that your email has been confirmed — unconfirmed accounts can't fully sign in.
  • Using GitHub OAuth? Make sure you're authorizing the same GitHub account the profile was created with.
  • Try a magic link from Log In as a fallback if password sign-in isn't working.

Community feed not updating in real time

The feed relies on a persistent Realtime connection — a flaky network (or an aggressive browser extension blocking WebSockets) can cause it to fall back to a static view. Refreshing the page re-establishes the connection.

Something looks broken on my screen size

Tip
The site has been checked across phones, foldables, tablets, laptops, and ultrawide monitors (see Responsive Design). If something still looks wrong at your specific width, it's worth reporting via Feedback with the approximate screen width and browser.

Still stuck?

Ask in the Community, or leave details on the Feedback page — see Feedback & Contributing for what to include.
