Support

FAQ

Quick answers to the questions we hear most often.

Account

QuestionAnswer
Do I need to verify my email?Yes — every account is confirmed via email before it's fully active.
Can I sign in with GitHub?Yes, GitHub OAuth is supported alongside email/password and magic links.
Can I change my username later?Username changes are handled from Settings; availability is checked in real time.

Expert Advisors

QuestionAnswer
Which EA should I start with?See Quick Start for a quick comparison, or Execution Systems for the full breakdown.
Do I need to compile anything?No — you download a ready-to-run .ex5 file. See Installation.
Should I test on demo first?Yes, always — see the warning in Quick Start.

Community

QuestionAnswer
Is the Community feed public?No — it's only visible to signed-in NUKRAX accounts.
Can I direct-message other traders?Yes, direct messages are part of the Community feature set.
