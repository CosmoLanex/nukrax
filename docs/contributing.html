Feedback & Contributing

How to share feedback, report issues, and suggest features — NUKRAX's version of “contributing.”

How to contribute to NUKRAX

NUKRAX isn't an open-source project, so "contributing" here means something different than a pull request: sharing feedback, reporting issues, and suggesting features through the channels built for it.

The Feedback page

The Feedback page is the primary channel for bug reports and feature requests. Include what you were doing, what you expected, and what actually happened — screen width and browser are especially useful for anything layout-related.

Community discussion

The Community feed is a good place to float an idea informally before submitting it as formal feedback, or to see if other traders have run into the same thing.

What happens after you submit feedback

Info
Feedback doesn't go into a public tracker today — it's reviewed directly. Shipped changes that originated from user feedback are noted in the Changelog where relevant.

Planned: public feature request board

Planned
A public, votable feature-request board (so traders can see and upvote what others have suggested) is being considered, but isn't part of the platform today.
