# Security Policy

## Reporting a Vulnerability

If you discover a security issue related to the NUKRAX website, this repository, or any official NUKRAX platform, please report it privately rather than opening a public issue.

**Contact:** [security@nukrax.com](mailto:security@nukrax.com)

Please include where possible:

- A clear description of the issue
- Steps to reproduce
- Any relevant logs, screenshots, or proof of concept

## Scope

This policy covers:

- [nukrax.com](https://nukrax.com) and its pages/subdomains
- This repository and other public NUKRAX repositories under [github.com/CosmoLanex](https://github.com/CosmoLanex)

It does not cover third-party brokers, platforms, or services that NUKRAX integrates with but does not operate.

## Response

Reports are reviewed as they come in. There is no formal bug bounty program at this time, but responsible disclosure is appreciated and will be acknowledged.
