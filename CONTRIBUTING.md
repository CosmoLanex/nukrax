# Contributing

Thanks for taking a look. A quick note on how this repository works before opening anything.

This repository contains the source for the NUKRAX web platform — a proprietary product built and maintained by Cosmo Lanex. It isn't an open-source project, and external code contributions or pull requests aren't currently accepted here.

## Found a bug?

If you've spotted something broken on [nukrax.com](https://nukrax.com) or an issue in this repository (a dead link, a rendering bug, outdated content), feel free to open an issue, or report it directly:

- **Feedback:** [feedback@nukrax.com](mailto:feedback@nukrax.com)

## Security issue?

Do not open a public issue for security vulnerabilities. See [`SECURITY.md`](SECURITY.md) instead.

## Want to work together?

For partnerships, integrations, or collaboration inquiries:

- **Partnerships:** [partners@nukrax.com](mailto:partners@nukrax.com)

For general questions about NUKRAX products or services:

- **Contact:** [contact@nukrax.com](mailto:contact@nukrax.com)
- **Support:** [support@nukrax.com](mailto:support@nukrax.com)

## Brand use

The NUKRAX name, logo, and brand assets in this repository are proprietary and protected — see [`LICENSE`](LICENSE) before using, referencing, or redistributing anything from this repository.
